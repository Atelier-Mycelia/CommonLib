# Introduction
These are a bunch of util scripts that some of our other packages might need. Feel free to use these in your own
projects, regardless of whether they contain any of our other packages.

# Installation
1. Open Unity → Window → Package Manager.
2. Click the ⊕ (plus) button → **Add package from Git URL…**
3. Paste the following URL: https://github.com/Atelier-Mycelia/UnityUtils.git?path=Packages/com.ateliermycelia.unityutils
4. Click **Add**. Unity will fetch the package and make it available in your project.
5. If it asks you to install TextMeshPro, do so.
